#📱 Calculator

A fully functional calculator application. Features a clean, intuitive interface with support for all basic arithmetic operations, parentheses, percentages, and decimal calculations.

## 🧮 Features

### 🔢 **Basic Operations**
- **Addition (+)** - Add numbers
- **Subtraction (-)** - Subtract numbers
- **Multiplication (×)** - Multiply numbers
- **Division (÷)** - Divide numbers

### ⚡ **Advanced Features**
- **Parentheses ()** - Support for complex expressions with proper precedence
- **Percentage (%)** - Calculate percentages
- **Decimal Point (.)** - Work with floating-point numbers
- **Clear (AC)** - All clear function to reset the calculator
- **Equals (=)** - Evaluate expressions with correct operator precedence

## 🛠️ Technology Stack

- **JavaScript (ES6+)** - Programming language
- **HTML5** - Semantic markup
- **CSS3** - Styling with modern features
- **Git** - Version control
